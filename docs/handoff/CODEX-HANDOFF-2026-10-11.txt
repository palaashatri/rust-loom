6. PARALLEL PROTOCOL
--------------------
1. Each lane: `git clone https://github.com/palaashatri/rust-loom.git ~/<lane>-loom`
   (fresh), work there, never in another lane's clone or in the Windows checkout.
2. Failing test first, then fix. Test behaviour (accessibility tree, element bounds,
   pixels, exported bytes read by an independent reader), never source strings.
3. Deliverable per lane = `git add -N . && git diff --binary > ~/<lane>.patch` (binary
   because a Present test fixture contains NUL bytes) + a <30-line report: commands,
   pass counts, changed files, anything NOT done, ceilings touched.
4. Integrator applies patches to the Windows checkout with `git apply --3way`, runs the
   audits, commits, pushes, watches CI (api.github.com/repos/palaashatri/rust-loom/
   actions/runs). Apply order when patches overlap: L6 -> L4 -> L3 -> L1/L2/L5/L7.
5. Hostile reviewer (Sol): receives the patch + report, re-runs the gates, mutation-
   checks every new test (break the code under test; a test that cannot fail is not
   evidence), drives the real nightly binary, and answers APPROVE / APPROVE_WITH_CHANGES /
   REJECT with numbered findings, severity 1 (data loss/crash/corrupt export/unsafe),
   2 (wrong output or broken primary workflow), 3 (polish). Reviewer is read-only on
   product code. The integrator only merges APPROVE or fixed-then-re-reviewed patches.
6. Final acceptance round (after lanes merge): one Sol pass on Windows (live, nightly
   exe, UIA dump, Office COM on exports) and one on Linux (private Xvfb + AT-SPI, nightly
   tar.gz). Output per-gate PASS/FAIL/UNVERIFIED with evidence paths. Only then may L9
   record ACCEPTED, and only for an app whose every gate in AGENTS.md section 13 passes.

8. PITFALLS LEARNED THIS SESSION
--------------------------------
- Headless windows report width 0 before layout; absolute x from parent.width goes
  negative (dialog buttons off-screen). Clamp with max(0px, ...).
- cargo test does not rebuild the app binary: `cargo build -p loom-<app>-app` before
  `--screenshot`.
- A fixed `LoomButton` height (28 px) is cramped at 2.0 text scale.
- Raw PDF byte greps no longer work (glyph ids): use loom_pdf::inspect (test-support).
- Present's tests/pictures.rs contains NUL bytes: use `git diff --binary`.
- A one-line shared edit (command_palette.slint) was made by two coders: expect
  harmless duplicate hunks; use --3way.
- Windows PowerShell 5.1 has no `&&`, no `wc`; Git Bash path conversion mangles
  /mnt/c and \\wsl$ arguments (use MSYS_NO_PATHCONV=1 or PowerShell).
- Agents that spawn their own polling monitors produce thousands of stale
  notifications: forbid timer/monitor loops in worker prompts.
- Power loss twice: everything uncommitted in WSL clones survived (ext4) but running
  jobs died. Commit/push after every verified milestone.
- Subagent usage limits hit mid-edit: re-read git status/diff before resuming a worker.
- The owner's weekly usage budget is limited: prefer one Sol review per platform at the
  end of a round over per-patch reviews; do not run duplicate full suites in many clones.

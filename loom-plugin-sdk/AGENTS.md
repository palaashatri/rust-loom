# AGENTS.md

Rules for agents working in this repository. These are binding.

## Contract

1. Do not execute WASM. The runtime is BLOCKED (RFC-0009); the host crate
   must remain execution-free.
2. Do not add networking code of any kind. This is an offline, local-first
   component. Network checks are permission metadata only.
3. No `unsafe` blocks. If you believe one is required, justify it in an RFC
   first; the current codebase is `#![forbid(unsafe_code)]`.
4. No hardcoded absolute paths. Use `CARGO_MANIFEST_DIR` at build time and
   relative or temp paths at runtime.
5. Every public item must have a doc comment. Lib crates enforce
   `#![deny(missing_docs)]`.
6. Dependency additions require a license check (MIT/Apache-2.0 compatible)
   and a note in `DEPENDENCIES.md`. Pin via `Cargo.lock` (committed).
7. Never commit binary fixture zips. Fixtures are generated by tests into
   `target/fixtures/` from committed text sources.
8. Tests must assert real behavior: no `assert!(true)`, no placeholder
   expectations. Security rejections must assert that nothing was extracted.
9. Run before reporting completion:
   `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`,
   `cargo test --workspace`, `cargo build --release`.
10. Keep implementation status honest: COMPLETE vs FUNCTIONAL_WITH_LIMITATIONS
    vs EXPERIMENTAL vs SCAFFOLDED vs NOT_STARTED. Unimplemented work stays
    visible in `TASKS.md` and `ROADMAP.md`.

## Ownership

- `crates/loom-plugin-manifest`: schema, validation, version compatibility.
- `crates/loom-plugin-host`: store, install security, permissions.
- `crates/loom-plugin-cli`: CLI + fixture generation.
- `docs/rfcs/`: cross-cutting ABI and sandboxing decisions.

Cross-crate contracts (manifest schema, HostError taxonomy) change only via
RFC or ADR.

# Loom Plugin SDK

Sandboxed extension system for the Loom creative suite: plugin package
format, manifest validation, safe installation, and permission checks.

This milestone delivers the **package/manifest/host foundation** in Rust.
WASI/Wasm execution is intentionally NOT implemented yet (see
`ROADMAP.md` and `docs/rfcs/RFC-0009-plugin-abi-and-sandboxing.md`).

## Repository layout

```text
crates/loom-plugin-manifest  manifest schema + validation + version compare
crates/loom-plugin-host      store, safe zip install, permission checks
crates/loom-plugin-cli       loom-plugin binary (validate/install/list/remove)
docs/rfcs/                   RFC-0009 plugin ABI and sandboxing
```

## Quick start

```sh
cargo test --workspace                 # generate fixtures + run all tests
cargo run -p loom-plugin-cli -- --help
cargo run -p loom-plugin-cli -- validate crates/loom-plugin-cli/fixtures/demo/manifest.json
```

The demo package zip is generated by tests into
`crates/loom-plugin-cli/target/fixtures/demo.loomplugin` — binary zips are
never committed.
